# SeeLiebe – Webseite

Statische Webseite für das Hausboot SeeLiebe (WOMA D12) in der Marina Röblinsee.

## Inhalt
- `index.html` – die Seite
- `impressum.html`, `datenschutz.html`
- `media/` – Fotos und Luftvideo
- `fonts/` – Schriften (lokal eingebunden, kein Google Fonts)

## Veröffentlichen mit GitHub Pages
1. Repository öffnen → **Add file → Upload files**
2. Den **Inhalt** dieses Ordners (nicht den Ordner selbst) ins Fenster ziehen, inkl. `media/` und `fonts/`
3. **Commit changes**
4. **Settings → Pages → Branch: main / (root) → Save**
5. Nach 1–2 Minuten ist die Seite unter `https://<benutzername>.github.io/<repository>/` erreichbar

## Anpassen
- Anfrage-E-Mail: in `index.html` ganz oben im Skript bei `CONFIG`
